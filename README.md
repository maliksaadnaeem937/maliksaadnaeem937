## 1. Deep Search Multi-Agent v3

**Python | LangGraph | LangChain | RAG | ChromaDB | BM25 | Cohere Rerank | Groq**

An asynchronous multi-agent research system that automates the end-to-end research process, from planning and web discovery to content extraction, retrieval, and report generation.

### Key Features

- **Multi-Agent Orchestration:** Uses LangGraph state graphs to coordinate research planning, URL discovery, web scraping, content validation, and report generation.
- **Human-in-the-Loop Planning:** Enables users to review, edit, and approve research plans before execution.
- **Automated Web Research:** Uses Crawl4AI and DuckDuckGo Search to retrieve and process relevant web content.
- **Hybrid Retrieval:** Combines BM25 keyword search with ChromaDB vector search using `BAAI/bge-small-en-v1.5` embeddings.
- **Context Reranking:** Integrates Cohere Rerank (`rerank-v3.5`) to improve the relevance of retrieved research context.
- **Structured Generation:** Uses Groq with `llama-3.3-70b-versatile` and Pydantic-based structured outputs to generate organized research reports.

## 2. Tiny-GPT

**Python | PyTorch | Transformer Architecture | Self-Attention**

A compact GPT-style language model implemented from scratch in PyTorch to explore transformer architecture and next-token text generation.

### Key Features

- **Token and Position Embeddings:** Represents input tokens and their positions within a sequence.
- **Causal Self-Attention:** Implements masked attention to prevent the model from accessing future tokens.
- **Multi-Head Attention:** Processes contextual relationships through multiple attention heads.
- **Transformer Components:** Includes feed-forward networks, residual connections, and layer normalization.
- **Next-Token Prediction:** Trains on a small, handcrafted text corpus to predict subsequent tokens.
- **Text Generation:** Generates text autoregressively by sampling predicted next tokens.

**GitHub:** [Tiny-GPT](https://github.com/maliksaadnaeem937/Tiny-GPT)

*An educational implementation designed to demonstrate the core components of a GPT-style transformer. Due to the small training corpus, generated text is experimental.*
